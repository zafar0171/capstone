# Capstone-- Readme

This project was carried out in principle of CRISP-DM.
In this project, I emphasized the importance of a thorough EDA process and how the process of EDA is an iterative and consequential in nature.
This dataset was massive and had to put a lot of efforts in cleaning, validation and tackling class imbalance.
The final model building process was comparatively way easier than the rest part of this Data Mining project.
Through this project, I used my analytical and attention to details skill completely...


## Objective:- To find out the most important characteristics/attributes of defaulting customers and allot loan based on the predictive model based on it

# Key highllights
* Automatically Validated data types using custom functions.
* Class Imbalance tackled.
* Performed Robust Feature Engineering

## Dataset highlights:

* 800000 data points with 74 attributes.
* Cardinality, missing values and outliers.
* Presence of Multi-collinear attributes.

Our base model is Logistic regression, while the best model is random forest.
